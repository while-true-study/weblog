# v1.1.0 - Load Test & Measured Limitations

## Added

- Docker 기반 k6 부하 테스트 환경
- loadtest 프로필 전용 notification handler delay injection
- loadtest 프로필 전용 테스트 데이터 bootstrap
- baseline / 100ms delay / 300ms delay / mixed-outbox 시나리오
- `docs/load-test-v1.md` 측정 결과 문서

## Key Findings

- 댓글 API p99: `44~52ms` 범위로 안정적
- COMMENT outbox 평균 지연: baseline `17.8s` → `300ms` delay `148.0s`
- drain time: baseline `32s` → `300ms` delay `294s`
- mixed 시나리오에서 POST search outbox도 평균 `103.6s` 지연
- Outbox는 트랜잭션 경계를 보호했지만, shared relay/process coupling은 남아 있음을 확인

## Known Limitations

- search와 notification handler가 같은 `OutboxEventScheduler` / `OutboxEventOrchestrator` 흐름을 공유한다.
- 느린 notification handler가 mixed 상황에서 search outbox 처리에도 영향을 줄 수 있다.
- v2에서는 RabbitMQ + notification-service로 notification 처리를 별도 실행/배포/스케일링 단위로 분리할 예정이다.
